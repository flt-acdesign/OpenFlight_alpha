User Guide

This tool visualizes flight data from a CSV file.

  • Choose CSV File: Select your data file. It must contain a header row starting with time,.... Key columns like time, LATITUDE_m, LONGITUDE_m, ALTITUDE_m, TAS, nz are needed for basic plots. Other columns (e.g., EAS, Mach, VSI_ms, load factors, control moments) enable their specific plots.
  • Time Range: Enter start and end times (in seconds) to focus the plots on a specific interval.
  • V Lines: Enter times (in seconds) to draw vertical dashed lines on the time-series plots for reference. Red line for Time 1, Blue line for Time 2.
  • Aspect Ratio: Set the desired width-to-height ratio for the plots (e.g., 1.77 for 16:9).
  • Columns: Choose how many columns to arrange the visible plots into.
  • Update Plot: Apply changes to time range, aspect ratio, or columns.
  • Show/Hide Plots: Use the checkboxes below the controls to toggle the visibility of individual plots. Use "Show All" / "Hide All" for quick selection.

Plots will update automatically when the file is loaded, visibility is changed, or the window is resized. Use the "Update Plot" button after changing time range, aspect ratio, or column count.
